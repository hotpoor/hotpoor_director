# 微信模式

登录工作台，点击顶部「微信模式」。这是导出档案阅读器，不是微信客户端，不发送消息，不自动读取或解密微信数据库。

## 导入与阅读

点击「导入聊天记录」，选择文件并检查前五条预览，再确认导入。支持 UTF-8 JSON、CSV、TXT。每文件创建独立会话，最多 10 MB / 20,000 条，保留原文件顺序。首次导入后可浏览、按消息正文/发送者/时间搜索、每次加载 100 条、导出完整 JSON。重试同一请求不会重复创建会话，重新选择文件则视为新导入。

JSON 可使用 `{ "title": "会话名", "messages": [...] }` 或消息数组；消息包含 `sender`、`time`、`text`，可选 `is_self`（布尔值）和 `type`。CSV 使用同名列，也支持「发送者、时间、内容」。TXT 每条消息以 `2026-10-29 09:30:00 张三` 或 `[2026-10-29 09:30:00] 张三` 开始，后续多行为正文。时间保留原值，不猜测时区或重新排序。输入格式不符合约定时拒绝导入，不跳过坏记录。格式示例可在导入面板下载。

目前导入消息的文字和媒体类型说明，不提取本地路径、不请求消息中链接、不加载导出 HTML 中的脚本，也不导入图片、语音或视频文件。微信加密数据库、原生恢复备份、ZIP 和任意第三方 HTML 导出暂不支持。真实数据需先从微信导出为可读文件，再转换为上述格式；不会把格式示例自动填入真实会话。

## 存储选择

- 当前账号数据库：消息保存在账号私有实体中；桌面使用本机数据库，线上使用服务器数据库。
- 云存储：可从已有配置选择具体七牛 / OSS / COS，无须切换全局启用项。正文使用 AES-256-GCM 加密后上传到 `<前缀>/wechat/<账号 UUID>/<归档 UUID>-<对象 UUID>.enc`。上传后回读，校验大小、SHA-256 和解密结果。账号数据库只保存会话标题、数量、时间范围及云对象索引，不保存云归档的消息正文；云对象不进入普通公开素材列表。

读取需要当前账号登录、对应云配置以及该运行端账号目录的 `.wechat-archive.key`（32 字节、0600）。必须备份账号数据目录、数据库和云对象。密钥丢失时无法解密。不同运行端不会自动同步解密密钥。删除云配置或修改存储位置会使旧档案暂时不可读取；同位置轮换 AK/SK 不影响归档。云存储请求失败时不发布未验证的会话，原导出文件保留；中断可能留下未引用的加密对象，不自动删除。

微信档案不提供分享链接，不纳入项目同步。线上同步 AK 无法访问微信接口，只有网页登录的当前账号可以读取。云端密钥由服务器持有，这不是端到端加密；服务器会在登录账号阅读时解密。

## 验证

`python -m pytest tests/test_wechat.py tests/test_cloud_storage.py -q` 验证格式、加密完整性、密钥持久化、云端密文回读、真实 PostgreSQL 的导入/分页/搜索/导出。`node_modules/.bin/electron scripts/smoke-wechat.cjs` 用隔离数据验证界面与选定云配置、XSS 转义和窄屏布局，不上传真实聊天数据、不发起付费模型调用。
