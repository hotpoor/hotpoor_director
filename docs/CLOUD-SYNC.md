# 云端工作站与双向版本同步

入口：`https://api.xialiwei.com/hotpoor/director`。云端复用此仓库的画布、评论、PIN、标注、模型 Tab 与云存储界面。

## 使用顺序

1. 在云端使用已有 API 邮箱账号登录，在「云存储直传设置」中保存并启用一套具有 HTTPS 访问域名的存储配置。可以保存多个厂商、同厂商多套配置。要在云端生成，再配置该账号的 service-inference Key。
2. 桌面客户端点击顶部「同步云端」，添加名称和完整 HTTPS 域名 / 产品路径。最多保存 20 个目标，每个目标独立授权。支持粘贴该云端签发的 Director Access Key，也支持浏览器授权。
3. 点击「登录云端并授权」。客户端唤起系统浏览器，核对双方显示的 8 位授权码，在已有云端账号中批准。用户选择有效期（7 / 30 / 60 / 90 天、1 年、自定义日历日期或永不过期）后，桌面轮询领取仅能访问 Director 的 AK。浏览器授权页支持创建多个具名 AK，查看创建 / 到期 / 最近使用时间，调整有效期或单独撤销；自定义日期按浏览器所在时区当天结束计算。
4. 打开项目，先「比较差异」，再提交。开启该项目、该云端的自动同步后，卡片会显示目标名称与本地相对上次同步的状态。每 10 秒检查已保存修改与云端新版本；有运行中的任务时等待结束，有云端新修改时暂停并提示。
5. 选择「拉回新副本并回传」会创建新的本地项目 UUID；卡片、素材、任务、评论块、消息与连线 UUID 也重新分配并整体修正引用。原项目保留，打开新副本。
6. 新副本保存成功后自动回传接收记录，其中关联云端版本哈希、新本地项目 UUID 和实体映射。回传失败时本地副本仍然可用，点击「重试回传记录」继续；同一目标、谱系、版本重复拉取不会再次创建副本。

云端项目列表也可以直接拉到本地，不必预先创建空项目。本地模型参数和已有结果随项目保留；ComfyUI 执行仍在桌面进行，云端直接执行 service-inference 模型。拉回素材用于本地参考生成时，会先下载到本地缓存并检查大小和已有 SHA-256。

## 差异与版本规则

- 项目、素材、云上传、生成任务、评论及消息包每次真实数据库写入，都在**同一事务、同一分片**写入 `change_event`，保存修改前后值、实体 UUID、项目 UUID、操作类型和记录时间。事务回滚时历史同时回滚。读取、鼠标移动及尚未保存的输入不产生历史事件。
- 「修改历史」按服务端时间分页读取并展示字段级差异，不自动清理旧历史。
- 同步使用规范化 JSON 的 SHA-256 表示内容版本，UUID 表示对象身份。时间帮助查阅先后，**不以设备时间直接判定谁覆盖谁**。
- 比较共同版本 / 本地版本 / 云端版本。按卡片 ID 比较卡片字段，避免数组顺序改变让整张画布成为冲突。
- 提交携带预览的本地、云端内容哈希；预览后任意一侧变化都会要求重新比较。双方修改时，可先拉回新副本，或明确勾选「保留云端旧项目并提交本地为新版本」。本轮不提供自动逐字段合并。
- 每次内容不同的云端提交创建新的云端项目 UUID，保留旧项目，并写入 `sync_commit`（快照、父提交、来源、时间、哈希）。`sync_head` 指向该谱系最新版本。`sync_link` 保存本地映射、共同版本与每个目标状态。
- 回执独立于内容提交，不要求云端停留在被接收的旧版本；它不覆盖项目，也不重新生成 UUID，因此不会来回同步形成无限副本。
- 完整差异可以导出 JSON。卡片徽标表示本地相对最近同步内容的状态，不保证远端在显示后没有新修改；每次真正提交都会重新检查云端版本。

## 资源与密钥

- 本地资源第一次提交至某个目标时，客户端先用 Director AK 请求该目标的存储上传凭证，按云端**当前启用的配置**上传；七牛为短期单对象 POST Token，OSS / COS 为短期 PUT URL。长期存储 AK/SK 不回传给桌面。
- 上传完成并通过云端大小、类型、公网访问校验后，本地实体增加 `cloud_versions[target_id]`，记录 URL、SHA-256、大小和验证时间。不同同步目标分别保留地址，原文件继续存在。
- 已有公网资源直接保留其云端地址。图片标注只保存坐标与笔迹，视频评论只保存起止秒数，不额外上传标注图或裁剪视频。
- 云端新上传的服务器本地素材，会在为同步准备快照时先转存到该账号启用的云存储。没有配置时明确报错，保留原素材。
- 本轮不自动删除本地文件，也不提供一键清理：只有大小 / 类型校验不够支撑不可恢复删除。应在核验远端完整文件校验和、备份及其他项目引用后，再加入可恢复清理流程。
- 同步 AK 不允许修改云端设置或执行模型；这些操作必须通过云端浏览器登录。同步不传本地密码、会话、ComfyUI 地址、磁盘路径、推理 Key 或存储长期密钥。每个本地账号的同步配置存于 `.director-sync-<owner_uuid>.json`，权限 0600，不进入 Git。
- 上传中断可以重试；已确认资源的地址先保存，本地版本不会因网络失败被删掉。生成中的项目暂不提交，避免把远端运行任务错误地当作可执行的本地任务恢复。

## 两端维护

本仓库维护唯一的画布 / Tornado 实现；API 仓库通过以下命令导入源码及 SHA-256 清单：

```sh
python scripts/export-cloud-runtime.py /path/to/api_xialiwei_com
```

API 项目的 `director.py` 负责账号与 AK、授权页、URL 前缀、内部请求校验和每账号配置隔离，内部 Tornado 服务只绑定 loopback。云端实体仍根据 UUID 求余路由到两个数据库，跨分片提交使用独立协调库。

线上现有 API PostgreSQL 未开启 prepared transactions，Director 使用独立实例 `127.0.0.1:5544` 的 `hotpoor_director`、`hotpoor_director1`、`hotpoor_director2`，开启 `max_prepared_transactions=32`；无需重启原有 API 数据库。云端浏览器账号与 AK 保存在原 API 索引库的 `director` schema。

## 验证

- `tests/test_sync.py`：引用重写、UUID 不误改提示词、三方差异、请求幂等、预览后冲突、审计历史、匿名权限。
- `tests/test_cloud_gateway.py`：临时 API PostgreSQL、浏览器授权、CSRF、AK 撤销、跨账号隔离、真实 FastAPI → Tornado 桥接；独立桌面进程推送、云端修改、双方冲突、拉回新 UUID、副本保留与回执去重。存储上传通过测试适配器模拟，无真实云存储费用。
- 先安装 `requirements-cloud-test.txt`；云端伴随仓库测试可通过 `DIRECTOR_API_CHECKOUT` 指定目录；目录或测试依赖不存在时跳过对应集成测试，不影响 Windows 桌面使用。

## 查看同步进度

打开画布右上角「队列」，切换「同步进度」Tab。按云端显示正在比较、上传并提交、拉回或回传、待处理差异、失败原因和最近成功时间；可打开对应云端处理差异 / 重试。上传目前显示等待指示，不提供字节百分比。生成任务仍在「生成队列」Tab 中。

## 服务器媒体存储

服务器版只使用对象存储：导入、评论附件、封面、参考素材和截帧均走云存储，后端拒绝本机媒体上传。云端生成结果通过内存转存到该账号启用的对象存储，记录 HTTPS 地址，播放由对象存储 / CDN 提供；不写入服务器 generated 目录。生成前必须启用存储。旧服务器文件保留，不自动删除。桌面仍可选择本机或云存储。

## 在线分享与成员

打开线上项目 →「分享与成员」。所有者 / 管理员可填写对方已注册并验证的邮箱，授予只读、可评论、可编辑或管理员权限；「允许生成」独立勾选，仅编辑 / 管理员可用。重复填写同一邮箱可更新权限，也可移除成员。

只读分享链接需明确选择 7 / 30 天、自定义日期或永不过期。未登录可直接观看画布和素材、阅读评论，不能评论或修改。登录后可点击「加入并打开」；评论仍需成员评论权限。不会自动发送邮件。链接到期或撤销，会收回由该链接获得的成员访问权；已单独邀请的成员权限独立维护。

每个人的模型 AK、模型发现和云存储配置只来自自己的账号。成员未配置 AK 时不会借用所有者 AK；生成任务绑定实际发起人和其凭据，后续查询沿用该绑定。新增媒体使用上传者的云存储配置；项目保留资源 URL。生成前还需启用自己的 HTTPS 云存储。

画布 / 评论的修改历史记录实际操作人。并发保存沿用 revision 检查，冲突时保留当前草稿，不静默覆盖。项目成员不开放云端版本同步写接口；所有者负责同步。新同步副本有新 UUID，不自动继承旧项目的成员或分享链接。分享撤销限制的是工作台访问，已公开的 CDN 媒体地址不因此自动失效。
