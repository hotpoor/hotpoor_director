# 可复用的视频提示词写法

## 先给素材分工，再写镜头

先列映射：哪张图负责人物身份、哪张负责场景、视频参考只借镜头还是动作、音频参考是音色还是内容。按每类素材各自的上传顺序编号，不按文件名猜编号。写完后对照实际 content 数组核查，删除不存在的引用。

可用骨架：

> [时长、单镜头或镜头顺序]。[主体及参考对应关系]。[场景与空间位置]。[动作起点→发展→终点]。[景别、机位与运镜]。[光线、色彩和风格]。[精确台词、环境声与音乐要求]。[最重要的连续性限制]。

从一个主体、一个主要动作、一个清晰镜头开始。复杂剧情拆为多个卡片生成，不把很短视频塞成多个来不及完成的场景。以秒为单位写阶段是创作意图，不是模型精确执行时间码的保证。

## Seedance 示例：人物在场景中行动

素材：Image1 为人物，Image2 为店内环境，Video1 为镜头运动示例。

> 8秒，连续单镜头。以 @Image1 的面部、发型和服装为准，环境采用 @Image2 的咖啡店，不复制 @Video1 中的人物，只参考其平稳横移的速度。0–3秒人物从门口走向木桌；3–6秒放下白色杯子并抬头微笑；6–8秒保持自然表情。中景，镜头缓慢向右平移，暖色窗光。人物外观与杯子形状保持一致，不切镜、不增加路人，不生成字幕。

首尾帧另写：

> 5秒，从所给首帧自然过渡到尾帧。人物缓慢转身看向窗外，镜头轻微推进；保持同一人物、衣服、房间和光线，不突然切场景。结尾构图尽量贴近尾帧。

此时 URL 分别作为 `first_frame` / `last_frame` 传，不仅是在正文里写“首帧”。

## H3 示例：人物与声音

素材：Picture1 为可用于此任务的人物图，Audio1 为获授权的音色参考。

> 8秒，固定中景。<Picture 1> 提供人物外观与服装；<Audio 1> 仅作为音色参考，使用新的台词，不复制原录音内容。主持人看向镜头，以平静亲切的语气说：“早上好，今天我们一起做一杯咖啡。”说话时轻轻举起杯子，结束后自然微笑。柔和室内日光，背景安静，无音乐、无字幕，保持人物身份和杯子外形一致。

适用时可附英文强调：`Reference the timbre only; speak the new dialogue without copying the original words.` 这仍是提示意图，提交成功不证明声音相似度或口型准确。

## 参数与正文不要冲突

- API 的 duration/resolution/ratio 决定结构参数，正文描述创作内容；正文“竖屏”但 ratio=16:9 应先统一。
- Seedance 需要声音时设置 generate_audio=true；无声音时 false。不要给不支持的模型添加同名字段。
- 指定要说的确切台词，并让字数与时长相称；不要同时要求“完全无声”和“清晰口播”。
- 用“固定机位”就不要同时写“快速环绕”；将“高级感”细化为景别、运动、光线、材质。
- 当前适配没有独立 negative_prompt；必要限制写入正文，不编造字段。
- 对同一镜头迭代时保留模型、素材、时长和其他参数，每次聚焦一项变化。保留原提示词与任务 ID 方便比较；不要把生成多条当作默认无成本操作。
